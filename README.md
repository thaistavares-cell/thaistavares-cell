## O que estou construindo

- **ETD (É Tudo Detalhe):** projeto pessoal de uma marca de moda pensada como sistema de dados, com arquitetura, governança e automação. Em construção, repositório privado.
    - **Gramática visual:** a identidade da marca definida como um conjunto de regras visuais, construída a partir de um corpus curado de imagens.
    - **Creative Engine:** pipeline de geração de imagens com IA, guiado pela gramática visual e integrado por API.
- **Monitor de editais:** automação que acompanha e arquiva oportunidades publicadas. Repositório privado.
- **Portfolio Hub:** projeto acadêmico de organização dos estudos.
